## 🔧 Troubleshooting Common Issues

### The app won't start
- Make sure your Windows is updated to at least version 10
- Close other programs that might be using too much memory
- Try running the app as administrator (right-click → "Run as administrator")

### Videos are buffering or lagging
- Check your internet speed — you need at least 10 Mbps for HD streaming
- Try lowering the video quality in the player settings
- Close other apps that use bandwidth (like game downloads or video calls)

### Subtitles don't appear
- Make sure you selected a subtitle language in the settings
- Try downloading subtitles again from the player's subtitle button

### Manga pages won't load
- Check your internet connection
- Try a different manga title — some older series may have fewer sources
